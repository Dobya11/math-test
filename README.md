# Математика — навчальні тести

Вебзастосунок для практики математики учнями 1–4 класів. Він генерує завдання
різних типів і рівнів складності, зберігає історію результатів та показує
підсумки учням і вчителям.

Завдання на додавання й віднімання розділені. У 1–2 класах є прості текстові
задачі; множення та ділення вивчаються окремими темами з 3 класу. У тестах для
3 класу геометрії немає.

Профілі й результати зберігаються локально у браузері цього пристрою. Дані не
синхронізуються між пристроями.
