# Система тестування · 2 клас

React/Vite-застосунок для вчителів та учнів 2 класу. Frontend розміщується на
Vercel, а облікові записи, класи й завдання зберігаються у Supabase (PostgreSQL
та Auth). Доступ до даних обмежується Row Level Security.

## Налаштування Supabase

1. Створіть проєкт Supabase.
2. У SQL Editor виконайте `supabase/schema.sql` один раз.
3. У **Authentication → URL Configuration** додайте URL локального сайту та
   домен Vercel до Site URL / Redirect URLs.
   У **Authentication → Sign In / Providers** увімкніть **Allow anonymous
   sign-ins**. Пароль і email не використовуються.
4. Скопіюйте `.env.example` до `.env.local` і заповніть значення з
   **Project Settings → API**:

   ```text
   VITE_SUPABASE_URL=https://<project-ref>.supabase.co
   VITE_SUPABASE_ANON_KEY=<publishable-or-anon-key>
   ```

   У frontend можна використовувати лише публічний anon/publishable key.
   Ніколи не додавайте `service_role` key до змінних `VITE_*`, Git або Vercel
   frontend.

5. Запустіть застосунок:

   ```sh
   npm install
   npm run dev
   ```

## Розгортання на Vercel

Імпортуйте репозиторій у Vercel із командою збірки `npm run build` і каталогом
виводу `dist`. У **Project → Settings → Environment Variables** додайте
`VITE_SUPABASE_URL` і `VITE_SUPABASE_ANON_KEY` для потрібних середовищ та
повторно розгорніть сайт. Маршрут `/class/123456` переписується на SPA entry
point через `vercel.json`.

Vercel Free підходить для статичного frontend. Ліміти збірок, функцій та
пропускної здатності залежать від актуальних умов Vercel; цей застосунок не
потребує Vercel serverless functions. Supabase має окремі квоти й політики
засинання безкоштовних проєктів — перевірте їх у своєму Supabase Dashboard.

## Перенесення даних зі старої версії

Дивіться окрему інструкцію [MIGRATION.md](./MIGRATION.md). Дані зберігаються у
`localStorage` браузера, а не у Vercel. Експортуйте їх на старому Vercel-домені
та завантажте архів у базу з кабінету вчителя.

Якщо `supabase/schema.sql` уже застосували до проєкту Supabase, не запускайте
його повторно: застосуйте лише
`supabase/migrations/20261109200500_legacy_data_archives.sql`.

## Поточний обсяг

- Анонімний вхід без email і пароля; профілі мають UUID і зберігаються в
  Supabase Auth.
- Учитель має один клас із шестизначним кодом; учень приєднується за кодом або
  посиланням `/class/123456`.
- Завдання класу зберігають вибрані заглушки `Тема 1` – `Тема 10` і кількість
  завдань (4, 8 або 12 на тему); підсумок рахується автоматично.
- Аналітика класу підписана на Supabase Realtime.
- У SQL-схемі підготовлені таблиці питань, відповідей і спроб, RPC для
  безпечного старту/збереження/завершення спроб, а також RLS-політики. Учень не
  має прямого доступу до таблиці правильних відповідей.
- Поки теми лишаються заглушками, застосунок не генерує і не показує вправи та
  не дозволяє починати спроби. Наявний генератор не видалено; його підключення
  потребуватиме узгодженого зіставлення конкретних тем і типів генератора.
- Архів старої версії зберігається окремо як JSON для дослідження. У старій
  історії немає відповідей на кожне питання, тож імпорт не створює нових
  облікових записів або спроб у живій аналітиці.
