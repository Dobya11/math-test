# Система тестування · 2 клас

React/Vite-застосунок для вчителів та учнів 2 класу. Frontend розміщується на
Vercel, а облікові записи, класи й завдання зберігаються у Supabase (PostgreSQL
та Auth). Доступ до даних обмежується Row Level Security.

## Запуск локально

1. Якщо Supabase ще не налаштований у репозиторії, виконайте `supabase init`,
   потім запустіть його командою `supabase start`.
2. Для нового проєкту виконайте `supabase/schema.sql`. Якщо таблиці вже
   створені, виконайте `supabase/migrations/20261110000000_create_assignment_with_questions.sql`.
3. Скопіюйте `.env.example` до `.env.local`. Візьміть локальний ключ командою
   `supabase status` і вставте його у `VITE_SUPABASE_ANON_KEY`:

   ```text
   VITE_SUPABASE_URL=http://127.0.0.1:54321
   VITE_SUPABASE_ANON_KEY=<ключ локального проєкту>
   ```

4. Увімкніть анонімний вхід у налаштуваннях Auth.
5. Запустіть застосунок:

   ```sh
   npm install
   npm run dev
   ```

## Розгортання на Vercel

Для хмарного розгортання вкажіть URL і публічний ключ свого проєкту у
`VITE_SUPABASE_URL` та `VITE_SUPABASE_ANON_KEY`. Імпортуйте репозиторій у
Vercel із командою збірки `npm run build` і каталогом виводу `dist`.
Маршрут `/class/123456` переписується на SPA entry point через `vercel.json`.

Vercel Free підходить для статичного frontend. Ліміти збірок, функцій та
пропускної здатності залежать від актуальних умов Vercel; цей застосунок не
потребує Vercel serverless functions. Supabase має окремі квоти й політики
засинання безкоштовних проєктів — перевірте їх у своєму Supabase Dashboard.

## Поточний обсяг

- Профілі зберігаються в Supabase; пароль і email не потрібні. Під час
  запуску можна вибрати профіль, сесії якого збережені в локальному сховищі
  браузера на цьому пристрої, або створити новий профіль.
- Збережені анонімні профілі доступні лише в тому самому браузері й на тому
  самому пристрої. Очищення даних браузера видаляє ці сесії; для перенесення
  профілю між пристроями потрібен окремий спосіб входу.
- Учитель має один клас із шестизначним кодом; учень приєднується за кодом або
  посиланням `/class/123456`.
- Кожне завдання класу містить приклади на додавання з вибором «Правильно» або
  «Неправильно» (4, 8 або 12 на тему).
- Аналітика класу підписана на Supabase Realtime.
- Учні бачать результати кожної спроби; учитель — середній результат кожного
  завдання та результати учнів.
- Окремі тренувальні тести мають аналітику за темами. Їхня історія зберігається
  у браузері цього пристрою.
- Тести для 2 класу охоплюють нумерацію та порівняння чисел, додавання й
  віднімання, вирази, таблиці множення і ділення, текстові задачі, величини,
  вимірювання відповідно до календарного планування Н. Листопад.
